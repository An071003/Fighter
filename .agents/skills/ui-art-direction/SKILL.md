# UI Art Direction Skill

Read `docs/08_INTERFACE_LAYOUT.md` and `docs/09_DESIGN_SYSTEM.md`.

- UI uses semantic HTML, React, Tailwind v4, shadcn and Motion for React; no Three imports.
- Build dark industrial aesthetic, very big typography but main craft remains visual hero.
- Primary CTA always visible, side drawer only on selection; on mobile use bottom sheet.
- Every button dispatches typed domain event, no fake clicks or random HUD numbers.
- Accent cyan used sparingly, 44px touch targets and clear active focus.
- Use one premium entrance motion and modest 120–500ms microinteractions. Reduced-motion no auto-spin or infinite micro loops.
- Score visual rubric and iterate screenshots desktop+mobile.
